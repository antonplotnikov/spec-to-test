# Screenshots

Add these PNG files before publishing (the README refers to them by name).
Use the example document `examples/password_reset.md` so the screenshots
contain no real project data. Recommended width: 1600 px.

| File | What to show |
|---|---|
| `analysis.png` | Requirements tab after Analyze, with the quality score panel open |
| `dashboard.png` | Dashboard tab with one filter applied and all three charts visible |
| `test-case-editor.png` | Test cases tab with a case open in the editor and its open questions |
| `test-design.png` | Test design tab for REQ-4 (boundaries) or REQ-8 (decision table) |

After adding them, replace the placeholder lines in the README's
"Screenshots" section with, for example:

```markdown
![Dashboard](docs/screenshots/dashboard.png)
```
