# Demo Shop — requirements

REQ-1: The home page must show the heading "Demo Shop".
REQ-2: A registered user must be able to sign in with a valid email and password and see "Welcome, Demo User" on the dashboard.
REQ-3: Signing in with a wrong password must show the error "Invalid email or password".
REQ-4: When the email field of the contact form is empty, the form must show the error "Email is required" and must not send the message.
REQ-5: A signed-in user must be able to delete their account from the account page.
REQ-6: The "go elsewhere" link must keep the user inside the shop.
